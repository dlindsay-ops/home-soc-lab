# home-soc-lab
**Overview**
This repository documents my hands-on cybersecurity home lab and my progression from security monitoring and incident investigation toward offensive security and penetration testing.
The lab is being built as part of my cybersecurity studies and is designed to provide practical experience with:
- Security monitoring and SIEM
- Windows and Linux systems
- Network security
- Log collection and analysis
- Detection and investigation
- Vulnerability assessment
- Offensive security
- Incident response
  
**Objectives**
My goals for this lab are to:
- Build and maintain a small virtual cybersecurity environment.
- Develop practical SOC and security-analysis skills.
- Learn how security events are generated and detected.
- Investigate suspicious activity using logs and security tools.
- Develop foundational penetration-testing skills in authorized lab environments.
- Understand attacks from both the offensive and defensive perspectives.
- Document my work and lessons learned as part of my cybersecurity portfolio.
  
**Lab Environment**
The lab currently uses:
- VMware Workstation Pro
- Ubuntu Linux virtual machine
- Windows 11 host
- Additional virtual machines and security tools will be added as the lab develops.

**Offensive Security**
